# Brand

Put the Kinan logo here as `kinan-logo.svg` (preferred) or `kinan-logo.png` / `.webp`, white or light artwork on a
transparent background. It is shown on a dark band in the header, the daily report, the slide player and the demo kit.

`npm run brand` (also run automatically before `npm run build` and `npm run demo:build`) embeds it into
`lib/brand-logo.ts`. Without a file, the K wordmark is used.
