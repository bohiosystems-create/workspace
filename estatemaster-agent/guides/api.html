KINAN · EstateMaster agent (mock API)

Reads and, after approval, writes to EstateMaster through its API.

What it is

The full loop against a mock EstateMaster API: the agent reads models and outputs through the API, proposes changes, and after a person approves, writes the change, asks EstateMaster to recalculate and reads the outputs back. Every call is logged and shown.

What to click

Daily feedProposed changes with their impact. Approve writes the change through the API (PATCH → calculate → GET outputs) and shows the new figures; Reject closes it. Rows open with details ›.
Financial modellingThe model as read from the API, with every input and output. Upload an export as well to compare.
Scenarios & stressStress runs in the API’s sandbox: EstateMaster calculates, the agent reads back.
ChatWhat-ifs (estimates, nothing written), “propose …” (a change request), “approve CR-104” (written after confirmation).
API calls (header chip EstateMaster · API)Every request and response, in order, with timing.
SettingsProviders, voice, market data, change memory, this guide and the demo video.

What the agent refuses, and why

Writing anything before approvalA what-if or a proposal never reaches EstateMaster. Only an explicit approval by a person triggers a write, and it is logged.
Writing to a model it has not read backAfter every write the agent reads the outputs again and compares them with what it expected; a mismatch is flagged, never hidden.
Assuming a missing inputAs in the other agents: the chat asks.
Showing an IRR it cannot reproduceThe base IRR is proved before IRR changes are computed.
Reporting an IRR where none exists“No IRR exists” is a possible answer.

Where the figures come from

Three kinds of figure appear, always labelled: EstateMaster’s (read from an export or the API, never recalculated), exact (computed by the agent from EstateMaster’s own cash flow, proved against EstateMaster’s IRR first) and AI estimate (two models, cross-checked; shown only when nothing exact is possible). Click any bold figure to see its working.
