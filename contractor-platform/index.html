Agentic control loop.
The platform detects a schedule breach, drafts a corrective directive, and — on your approval — issues it to the contractor over the right channel: a human crew receives an instruction via Procore/RFI; an autonomous fleet is dispatched a machine command via the Trimble / fleet MCP connector, which acknowledges and begins executing automatically.

Powering the agent with Claude.
The key configures which Claude model the Agent Console uses to draft corrective directives from the schedule and telemetry pulled over MCP. It is stored only in this browser (localStorage) and is never sent anywhere from this demo.

In production the key must live server-side — the browser calls your backend, which holds the Anthropic key and proxies the request. Never ship an API key in client-side code.

Connected systems — MCP

The platform speaks to the tools heavy-industry programmes already run on, through Model Context Protocol servers. Primavera P6 is the schedule of record; progress flows in, and directives and re-baselines flow back out.
