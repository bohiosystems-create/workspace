How consolidation works.
Every report is a dated snapshot from one contractor. The engine keeps the latest reported state per work package, reconstructs actual start / finish dates, extrapolates a completion forecast from the reported rate, and rolls it all up into the project timeline, S-curve and milestone forecasts. Nothing here is hand-entered on the plan side — the actuals are 100% report-driven.
